# NotchIsland

Плавающий «остров» у выреза камеры MacBook (macOS 13+). Задержи курсор на вырезе на полсекунды
или кликни по нему — остров раскроется.

- **Буфер обмена** — всё, что копируешь: текст, ссылки, картинки, файлы из Finder и свежие
  скриншоты. Клик копирует запись снова, перетаскивание отдаёт её в другое окно, булавка
  закрепляет навсегда. Незакреплённое удаляется через час (или через сутки, или хранится
  всегда — в настройках). Есть пауза записи.
- **Статистика** — процессор, память, сеть, диск, батарея и лимиты подписки Claude
  (сессия 5 ч и неделя). Любую карточку можно закрепить отдельным значком в строке меню.
- **Не засыпать** — экран не гаснет и Mac не уснёт на выбранный срок.

## Сборка

Нужен Xcode 15+ (Swift 5.9+).

```bash
./build.sh            # собрать build/NotchIsland.app (универсальный: Apple Silicon + Intel)
./build.sh dev        # собрать и запустить для разработки — без установки и автозапуска
./build.sh install    # собрать, заменить копию в /Applications и запустить
./build.sh dmg        # собрать установщик build/NotchIsland.dmg
```

Для правок кода хватит `swift build` — проверить, что всё компилируется.

## Обновления

Приложение обновляется само через [Sparkle](https://sparkle-project.org): при запуске и раз в час
смотрит `appcast.xml` на сервере, скачивает новую версию в фоне (только разницу с установленной,
если она есть) и показывает зелёную кнопку «Обновить» внизу острова.

```bash
./build.sh release 1.2    # собрать 1.2, подписать, посчитать дельты, обновить appcast.xml и залить на сервер
```

Нужны два локальных файла, которых нет в репозитории:

- `release.env` — куда заливать: `DEPLOY=user@host:/путь/к/папке`;
- `~/.config/notchisland/sparkle_private_key` — секретный ключ подписи обновлений (он же в связке
  ключей, запись `notchisland`). Без него новые версии не выпустить: установленные приложения
  принимают только обновления, подписанные этим ключом. Храни копию в надёжном месте.

Установщик последней версии лежит рядом с обновлениями: `download/NotchIsland.dmg`, страница
для скачивания — `Server/index.html`.

## Устройство

```
Package.swift                 Swift Package: одна исполняемая цель NotchIsland
build.sh                      сборка .app: бинарник + Resources/, ad-hoc подпись
Resources/                    Info.plist и иконка приложения
Server/                       страница для скачивания на сервере обновлений
Sources/NotchIsland/
  App/                        точка входа, AppDelegate, установка в /Applications, автозапуск
  Island/                     сам остров: окно у выреза, наведение, форма, размеры, верхняя строка
  Clipboard/                  история буфера (хранилище, запись) и вкладка «Буфер»
  Stats/                      замеры системы, графики и вкладка «Статистика»
  Claude/                     лимиты подписки Claude: вход Claude Code, сервер, строка состояния
  KeepAwake/                  режим «не засыпать»
  MenuBar/                    значки в строке меню и их общее меню
  Settings/                   страница настроек
  Updates/                    обновления (Sparkle) и зелёная кнопка «Обновить»
  Shared/                     форматирование, цвета, пути и ключи настроек, общие компоненты
```

## Данные

Всё хранится локально в `~/Library/Application Support/NotchIsland`:

- `Clipboard/` — история буфера и копии скопированных картинок (доступ только у владельца).
  То, что менеджеры паролей помечают как скрытое, не сохраняется.
- `claude-usage.json` — лимиты, которые пишет строка состояния Claude Code.

Лимиты Claude приложение берёт двумя способами: через вход Claude Code (`claude auth login`,
запись в связке ключей) — раз в минуту спрашивает сервер Anthropic; или как строка состояния
Claude Code в терминале (`NotchIsland --statusline`, подключается в настройках).
